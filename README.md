# Ветка firmware

Служебная ветка: здесь лежит прошивка последнего релиза для ESP32 DEVKIT1,
которую скачивает кнопка «Скачать и установить» в веб-интерфейсе устройства.

Ветку целиком пересоздаёт workflow `.github/workflows/build.yml` на каждом
теге `v*`. Руками сюда коммитить нечего — исходники живут в `main`.

Текущая версия: `2026.3.4` — [`2026.3.4/firmware.bin`](2026.3.4/firmware.bin)
